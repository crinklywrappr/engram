# 01: Define the cardinality shorthand in both skills

**What to build:** The `engram-recall` and `migrate` skills name the cardinalities
`1`, `?`, `*`, and `+`. Neither skill defines the symbols. Add a short list to
each skill. The list defines every symbol. `1` means exactly one. `?` means zero
or one. `*` means zero or more. `+` means one or more. Put the list where the
skill first names a cardinality.
